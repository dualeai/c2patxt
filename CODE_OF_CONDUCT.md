# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

The full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

## Scope

It applies in all project spaces — issues, pull requests, discussions, and security
correspondence — and in public spaces when an individual is representing the project.

## Reporting

Report unacceptable behaviour to `conduct@duale.ai`. Reports are handled
confidentially. For security vulnerabilities use the process in
[SECURITY.md](SECURITY.md) instead; this address is not monitored for those.
